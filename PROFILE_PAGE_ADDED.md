## 📍 How to Access Profile

### From Dashboard:
1. Click the **avatar** (with username first letter) in the top-right AppBar
2. Select **"Profile"** from the dropdown menu
3. View and edit your account information
4. Click **"Back to Tasks"** to return to dashboard

## ✨ Profile Features

### View Mode (Default)
- See username, email, account status
- Account creation date
- Last login time
- Click "Edit" button to make changes

### Edit Mode
- Update email address
- Change password (optional)
- Confirm new password
- Save or cancel changes
- Validation for password matching and minimum length
